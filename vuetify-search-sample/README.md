# Vuetify 3.8.2 検索画面

上部に検索条件、下部に `v-data-table` の検索結果を配置したVue 3のサンプルです。
検索条件はHTMLの `fieldset` で囲み、枠線上に `legend` の「検索条件」を表示します。
枠内の入力部品はVuetifyの `v-text-field` と `v-select` を使用しています。
Vuetifyは **3.8.2** に固定しています。36件の架空データで動作し、バックエンドは不要です。

## 起動

Node.js 22.12以上を用意し、このフォルダ内で実行してください。

```sh
npm ci
npm run dev
```

PC: `http://localhost:5173`。同じWi-FiのiPhoneは `http://PCのLAN内IP:5173` から開けます。
必要に応じてPCのファイアウォールでTCP 5173を許可してください。

```sh
npm test
npm run build
```

## 画面と動作

- キーワード：管理番号・件名・担当者の部分一致。全角英数字と大文字小文字を正規化。
- 区分・ステータス：選択した値で絞り込み。
- 登録日：開始日と終了日を含む範囲検索。片側だけの指定も可能。
- 複数の検索条件はANDで適用。
- 「検索」またはキーワード入力中のEnterで検索。入力変更だけでは結果は変わりません。
- 初回表示時は全件表示。「条件クリア」で条件を初期化して全件表示。
- 検索後は1ページ目に戻ります。列の並べ替え、10/20/50件表示、ページ切り替えはVuetify標準機能。
- 条件エラー、取得失敗、0件時のメッセージを表示。
- テーブルは固定ヘッダー・高さ420px。狭い端末ではテーブル部分を横スクロールできます。
- F3キーまたは「画面コピー（F3）」で表示中のページ領域をPNG画像にし、クリップボードへコピーします。

## F3による画面キャプチャ・クリップボードコピー

ページにフォーカスがある状態で修飾キーなしのF3、または「画面コピー（F3）」を押してください。
表示中のWebページ領域をPNGとしてクリップボードへコピーします。
コピー後はWord・PowerPoint・画像編集アプリ等、画像の貼り付けに対応する場所でCtrl+V等を実行します。

- `html2canvas` でDOMから画像を作成し、`navigator.clipboard.write()` と `ClipboardItem` でコピー。
- コピー範囲は現在の表示領域（スクロール位置・表示サイズ）です。ページ全体や別ページの行は含みません。
- アドレスバー、タブ、OS画面は対象外。コピー操作ボタンと通知も画像から除外します。
- F3の標準動作（ページ内検索・次を検索）は `preventDefault()` で抑止。
- Ctrl/Alt/Shift/Meta付きF3・IME変換中のイベントは処理しません。
- 長押し・コピー処理中の再実行を抑止。画面破棄時にリスナーを解除します。
- Clipboard APIへ渡すPNGはPromiseにし、画像生成をawaitする前に書き込みを開始します。
- 失敗時は画面にエラーを表示し、コピーできたと誤表示しません。

### 実行環境

**HTTPSまたはlocalhost** で開いてください。社内LAN内でも単なる `http://PCのIP:5173` では
Clipboard APIが利用できないことがあります。iPhone等では「画面コピー」ボタンを使います。
ブラウザの許可・組織ポリシー・埋め込みページのPermissions Policyによってコピーが拒否される場合があります。
ページ外（アドレスバー等）にフォーカスがあると、F3はページに届きません。

`html2canvas` はOSのスクリーンショットではなくDOMの再描画です。
CSS、外部画像、動画、iframe等は見た目が完全には再現されない場合があります。
対象のEdgeで実際に画像を貼り付け、画面とスクロール位置が期待どおりか確認してください。
画面取得のためにOSの画面共有ダイアログを開く処理や、画像をサーバへ送信する処理は含みません。

## 主なファイル

|ファイル|用途|
|---|---|
|`src/components/SearchPage.vue`|検索条件・結果テーブル・画面状態|
|`src/services/search.js`|入力検証・絞り込み・検索データ取得|
|`src/data/records.js`|架空のサンプルデータ|
|`src/main.js`|Vuetify登録、日本語表示、テーマ、アイコン|
|`src/utils/capture.js`|表示領域のPNG生成・クリップボード書き込み・F3イベント|

## C# APIへの接続

`src/services/search.js` の `searchRecords(criteria)` をAPI呼び出しに置き換えてください。
戻り値は `{ id, title, category, owner, status, registeredAt }` の配列です。
`registeredAt` は `YYYY-MM-DD` の文字列を使います。
現在は全件をブラウザに読み込んでからページ分割する構成です。
大量データでは `v-data-table-server` に切り替え、検索・並べ替え・ページ分割をサーバ側で行います。
画面の入力検証とは別に、API側でも入力検証とアクセス権確認を実施してください。

既存Vueアプリへ組み込む場合は `SearchPage.vue` と `services`・`data` を移し、
既存のVuetify設定にコンポーネント・日本語・MDIアイコン設定を合わせてください。
